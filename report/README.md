Run this script to export the report figures:

1) From the repo root:
   `python report/export_report_figs.py`

2) The images will be created in `report/figs/`:
   - `cnn_task1_bar.png`
   - `cnn_task1_arch.png`
   - `cnn_task2_loss.png`
   - `net_aug_loss.png`
   - `net_sgd_loss.png`

The LaTeX draft is in `report/interim_report_draft.tex` and references the figures
relative to the `report` folder.
